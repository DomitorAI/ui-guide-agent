# Security policy

## Reporting a vulnerability

Please **do not open a public issue** for a security problem.

Report it privately: [Security → Report a vulnerability](https://github.com/DomitorAI/ui-guide-agent/security/advisories/new).
Only the maintainers can see the report.

Include what you can:
- the component: server, desktop SDK, web SDK, Companion, `uiguide` tool, or install scripts;
- the version;
- the steps to reproduce;
- what an attacker could do.

Never include real API keys or personal data.

You will get an answer in the report.
Once a fix is released, the advisory is published, with credit to you if you wish.

## Supported versions

Only the latest release is supported.
Fixes come as a new version. The update notice shows the lines to run.
